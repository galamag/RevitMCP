## Что учесть при выборе

- Новый материал из `create_materials` без базы даёт ровный цвет без текстуры и класс `Unassigned`. Копия с `baseMaterialId` сохраняет текстуру и класс базы, но перекрасить можно только базу с ровным цветом.
- В режиме `realistic` виден внешний вид материала, а не цвет Shading из таблицы выше.
- Тип из `create_type` со своими слоями: все слои считаются ядром. Тип без `layers` остаётся точной копией базы со своими слоями.
